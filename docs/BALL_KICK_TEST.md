# Одноразовый тест подхода и прыжковой доводки

GUI: панель игры → роль `ball_kick_test` → запуск.
Голосовое меню: Tests → Ball approach and kick.
API: `game.start {"strategy":"ball_kick_test"}` с обычным lease в MANUAL.
Статус и остановка — `game.status` / `game.stop`, также штатный жёсткий стоп.

Это **не матч**: ворота, таблица направлений, визуальная локализация и kickoff
не используются. Сохранённые параметры игры не меняются. Мяч должен быть виден
впереди; автоматического кругового поиска нет. Освободите место для подхода,
прыжков и удара. Робот должен стоять на полу, не на стойке.

1. Встать в base_stand, установить игровую голову, получить свежий мяч.
2. Если мяч дальше 350 мм — повернуться к нему и выполнить штатный подход
   с наблюдением в движении (не более трёх подходов).
3. Выбрать ближайшую по знаку Y ногу, при Y=0 — левую. Затем только прыжки:
   сначала боковая доводка, затем вперёд. После каждого прыжка — свежий осмотр.
4. Цель: X не больше `game.kick_distance_mm + 10`, боковое отклонение от
   выбранного `game.kick_offset_mm` не больше 20 мм, дальность меньше 200 мм.
5. Выполнить один удар выбранного `motion.kick_type` с power=100 по текущему
   направлению корпуса и завершиться с reason=`kick_completed`.

Используются текущие калибровки прыжков `motion.jump_*_mm`; доля прыжка
ограничена диапазоном 0.1–1. После пяти прыжков без попадания в окно тест
завершается, **не возвращается к ходьбе** и не бьёт вслепую. Потеря мяча,
его уход дальше 350 мм во время доводки, ошибка движения или падение также
завершают попытку. Автовставания и повторения теста после ошибки нет.
Тело теста ограничено 120 секундами. Для повторения нужен новый явный запуск.
Пауза/Pick up, прервавшие попытку, не возобновляют её автоматически.

Высота и проекция мяча пока штатные: тест не исправляет ошибки геометрии.
Диагностика в логе имеет префикс `Ball kick test:` и показывает координаты,
выбранную ногу, направление/долю каждого прыжка и причину завершения.
