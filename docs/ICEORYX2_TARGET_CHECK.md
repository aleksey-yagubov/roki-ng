# Проверка iceoryx2 на новом образе

24 сентября 2026, CM4, SSH `root@172.30.0.1`. После перепрошивки исходники
восстановлены в `/opt/roki-ng` через rsync. Автозапуск dinit не изменялся.
GPIO, UART, камера и движения во время этой проверки не использовались.

## Окружение

- Linux 6.18.48-v8, AArch64, Python 3.14.7.
- iceoryx2 0.10.0, flatbuffers 25.12.19.
- Импорты `iceoryx2`, `Roki`, `libcamera`, `gpiod`, `msgpack` проходят.
- Конфигурация `/etc/iceoryx2/iceoryx2.toml` задаёт
  `global.root-path = "/run/roki-ng/iceoryx2"`.

## Воспроизводимая проверка

```sh
python /opt/roki-ng/tools/check_iceoryx2.py
```

Синтетический publisher и два subscriber в отдельных процессах (`spawn`).
Используются только публичные Python API iceoryx2; ctypes заполняет выданный
библиотекой участок памяти, а не реализует атомики или собственный ring.

Один publisher, максимум три subscriber, очередь каждого на два сообщения,
один удерживаемый sample на subscriber, safe overflow, без истории.
Каждая серия публикует 180 сообщений за 3 секунды, 60 Гц.

| Размер | Быстрый читатель | Медленный читатель | Максимальное время send |
| --- | --- | --- | --- |
| 64 байта | 180, без пропусков | 39, пропущено 140 | 0,019 мс |
| 800×650×3 + 16 байт | 180, без пропусков | 38, пропущен 141 | 0,052 мс |

Медленный читатель удерживает sample 80 мс. CRC до и после задержки совпадает:
publisher не перезаписал занятый sample. Проверены порядок sequence, размер,
маркер содержимого. Быстрый читатель для больших сообщений показал максимальный
возраст 4,07 мс, включая проверку CRC. Время send не включает заполнение памяти.
Это короткий smoke test, не оценка предельной производительности или real-time гарантия.

После завершения теста каталоги nodes/services пусты, больших сегментов кадров
в `/dev/shm` нет; остался глобальный management-объект iceoryx2 размером 16 байт.
Аварийное завершение читателя и восстановление publisher ещё не проверены.

## Что ещё не реализовано

Это проверка транспорта, не готовые camera/IMU rings. Требуются рабочие форматы
сообщений, интеграция захвата libcamera и опроса STM, привязка sequence,
проверки перезапуска и потери процессов.

При подключении только головы нельзя запускать обычный motherboard-worker:
даже `--skip-mixing` пока выполняет Rcb4 acknowledge. Сначала нужен режим без тела.
Сброс GPIO и команды телу этим тестом не выполняются.

Локальный набор тестов существующего runtime: 39 passed, одно предупреждение
GI о deprecated GLib.unix_signal_add_full.
