# Шаблон измеренного поля 3,40 × 2,40 м

Основан на замерах оператора, которые заменяют размеры первоначальной схемы.
Размеры карты идут по серединам белых полос толщиной 5 см: к внутреннему
просвету между двумя полосами добавлено 5 см суммарно. Просвет поля 335×235 см
даёт карту 340×240 см; круг внутри 85 см даёт диаметр по середине краски 90 см;
площадка внутри 114,5×24 см даёт 119,5×29 см. Подтверждённые размеры:
диаметр шести закрашенных точек — 5 см, длина трёх палочек — 15,5 см.
Начало координат в центре поля, X вдоль длины, Y поперёк; единицы params — метры,
углы — радианы.

| Разметка | Координаты центров / размеры |
| --- | --- |
| Шесть точек | X = −0,75 и +0,75; Y = −0,65, 0, +0,65; диаметр 0,05 |
| Три палочки | X = 0; Y = −0,76, 0, +0,76; длина 0,155 вдоль X, angle = 0 |
| Центральный круг | Центр (0, 0), диаметр 0,90 |
| Вратарские площадки | Глубина 0,29, ширина 1,195; передние линии X = ±1,41 |
| Ворота | Центры (±1,70, 0), ширина 1,00 (по схеме, ещё не измерена) |

В GUI: «Поле и ворота» → «Загрузить карту» → «Шаблон 3,40 × 2,40».
Кнопка создаёт только черновики и заменяет прежние дополнительные метки:
00–05 — точки, 06–08 — палочки, 09–14 — границы вратарских площадок;
15 выключена. Палочки перпендикулярны центральной линии. Толщина краски
field.geometry.paint_width задаётся равной измеренным 0,05 м.
Цвет и высота ворот сохраняются, measured сбрасывается до проверки оператором.
Покрытие не меньше 4,00 × 3,00 м. Назначение своих ворот не меняется.

Проверьте черновик, толщину разметки, цвет и высоту ворот, затем нажмите
«Сохранить всю карту». Требуется управление роботом (lease). Объекты записываются
последовательно с защитой expected_value, не одной общей транзакцией. При ошибке
часть карты уже могла сохраниться: устраните причину и завершите запись.
Не запускайте локализацию/игру до завершения сохранения. Карта применяется при
следующем запуске локализатора; кнопка шаблона сама не сохраняет и не двигает робота.
Заводские значения и существующая карта автоматически не заменяются.

Runtime обнаруживает точки отдельно от центрального кольца; в диагностическом
видео локализации обводит их голубым и показывает `spots N`. Это кандидаты,
а не подтверждённые ориентиры. Короткие отрезки дополняют поиск длинных линий.
Точки и палочки помогают сопоставлению, но не являются самостоятельным
доказательством положения или стороны симметричного поля. В timings_ms этап
marks измеряет их поиск отдельно.

Проверено локально на синтетических масках, в тестах фильтра/протокола и рендере
настоящей QML-панели. Качество обнаружения точек диаметром 5 см на реальной
камере зависит от расстояния, сегментации и калибровки проекции; полевые
измерения точности и времени обработки на роботе ещё нужны.
